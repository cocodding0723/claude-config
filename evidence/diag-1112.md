## 원인
1. **버튼 누락(주원인)**: `slack_notify.sh` 는 `chat.postMessage` 경로(`build_payload`)에서만 버튼 블록을 만든다. 파일 첨부 호출은 `files.completeUploadExternal` 이라 블록을 못 단다. `--options` + 파일 경로 조합이 조용히 버튼 없이 나갔다. (`--options` 없는 결정 카드도 경고 없이 나감: 11-11 `NOOPT` 카드 7건.)
2. **스레드 글 미해석**: `slack_poll.sh` 의 `collect_replies` 는 답글 레코드에 카드 메타(제목·태그)만 붙였다. 결정 번호와 'A'·'추천' 해석이 없어 메인이 어느 결정의 답인지 알 수 없었다.
3. **버튼 전달 문구 불일치**: `slack_socket.py` 가 메인에 `[Slack→메인] 결정: <제목> = <버튼 글자> (<ts>)` 로 보냈다. 결정 번호가 없어 반응·스레드 글의 `결정 D-xxxx = …` 와 형식이 달랐다.
4. **repo manifest 낡음**: `hubs/slack-bot-manifest.yml` 에 `interactivity`·`socket_mode_enabled: true`·이벤트 구독이 없고 라이브(`~/.config/lrm-hubs/slack-bot-manifest.yml`)와 다르다. 라이브 앱은 이미 켜져 있어 동작에는 영향 없음(동기화 변경안만 커밋).

| 1 | 파일 + `--options`: 버튼 카드를 먼저 `chat.postMessage` 로 올려 `ts` 를 기록하고, 파일은 그 스레드에 첨부. 첨부 파일이 없으면 카드도 보내지 않음. `--kind decide` 인데 `--options` 가 없으면 stderr 경고(`LRM_BTN_WARN=off` 로 끔) |

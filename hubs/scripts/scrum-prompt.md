## 쓸 것
`# {{NAME}}` 칸 하나. 아래 형식을 그대로 따른다.
- 맨 위 줄은 `# {{NAME}}`, 빈 줄, 그 아래 불릿만. 표·번호 목록·이미지·코드 블록 없음.
- 최상위 불릿: `**굵은 주제**` + 선택 `(진행 중|해야 할 일|검토 대기 중 하나만. 완료·병합 같은 다른 낱말 금지. 병합은 하위 불릿에 `병합` 으로 씀)` + 선택 `— 한 줄 보충`(마감이 있으면 `— 오늘 15시 마감`).
- 하위 불릿은 1단계만, 4칸 들여쓰기. 3단계 금지.
- 티켓은 `[LRM-n](https://basakansoft.atlassian.net/browse/LRM-n)`, PR 은 `[#n](https://github.com/Basakansoft/LoveRevolutionMaker/pull/n)`. 여러 개는 `·`, 범위는 `\~`.
- 하위 불릿 문장은 명사형 종결, 한 줄 40~60자 안팎(링크 글자는 빼고 센다, 길면 둘로 쪼갬), 마침표 없음. 이유·수치는 같은 줄 뒤에 붙인다(예: `오토마 시험 207개 통과`).
- 주제마다 진행 중인 작업이 있으면 `hub_progress` 에서 상세를 하위 불릿으로 적는다.
  - `진행: …` 지금 하는 일 한 줄. 끝낸 일과 남은 일을 구분한다.
  - `PR: [#n](링크) 상태` 열린 PR 마다. 상태는 `검사 통과`·`검사 실패 n건(이름)`·`검사 대기`·`초안`·`병합 대기` 중 재료에 있는 것만 쓴다.
  - `막힘: … — 풀어 줄 사람`. 막힘은 누가 풀어야 하는지(기획·서버·검수·본인)까지 쓴다. 재료에 근거가 없으면 `확인 필요`.
  - `결정: …` 재료의 결정 기록 중 팀이 알아야 하는 것만, 이유와 함께 한 줄.
- 주제마다 오늘 할 일이 있으면 하위 불릿 `오늘: …` 한 줄.
- `hub_progress` 의 갈래 이름(영문 슬러그)은 쓰지 않는다. 일의 내용으로 주제 이름을 짓는다. 같은 PR 이 여러 갈래에 나오면 한 주제로 합친다.
- 마지막 불릿은 `**막힌 것**: 없음`. 막힌 근거가 재료에 있으면 그 내용을 적는다.
- 재료의 `attachments`(화면·영상 파일)는 코드가 스레드에 따로 올린다. 본문에 파일 경로·이름을 쓰지 않는다. 어떤 주제의 화면·영상이면 `영상 첨부`·`화면 첨부` 라고만 하위 불릿에 적어도 된다.
- 개발 용어는 풀어 쓴다. 허브·워커·묶음 번호·결정 번호 같은 로컬 작업 용어와 AI 흔적은 쓰지 않는다.
- 전체 {{MAX_LINES}}줄 이하. 최상위 불릿 4~8개.
- 어제 칸의 항목은 상태를 이어 쓴다. 병합됐으면 완료로 쓰고 새 일을 올린다.

## 지킬 것
- 근거가 없는 내용은 쓰지 않는다. 오늘 할 일은 열린 PR·진행 중 Jira·HANDOFF 의 남은 일에서만 뽑는다. 확신이 없으면 `확인 필요` 를 붙인다.
- 재료·Jira·Confluence 에서 찾은 사실만 쓴다. 티켓 번호와 PR 번호를 지어내지 않는다.
- Atlassian 도구가 없거나 오류를 내면 읽은 척하지 말고 재료만으로 쓴다. 그때는 출력 맨 끝에 `{{NO_ATLASSIAN}}` 한 줄만 따로 붙인다(칸 본문에 설명을 쓰지 않는다).
- 출력은 칸 본문뿐이다. 머리말·설명·코드 펜스를 붙이지 않는다.

# 프로젝트별 설정 읽기

받는 사람·채널·이름 규칙처럼 프로젝트마다 다른 값은 `projects.toml` 한 파일에만 둔다. 이 스킬 본문에는 값을 쓰지 않고 **항목 이름**만 부른다.

## 파일 위치

| 구분 | 위치 | 추적 |
|---|---|---|
| 실제 값 | `~/.config/doc-kit/projects.toml` | git 밖(미추적). 개인 값이 저장소에 들어가지 않는다 |
| 틀 | 이 스킬의 `projects.example.toml` | 저장소에 추적. 값은 자리표시 |

환경 변수 `DOC_KIT_CONFIG` 로 다른 경로를, `DOC_KIT_PROJECT` 로 프로젝트를 지정할 수 있다. 실제 값 파일이 없으면 틀을 복사해 채운다. 값 파일은 백업해 둔다(설치기는 이 파일을 만들거나 지우지 않는다).

한글 프로젝트 이름은 TOML 규칙상 따옴표로 감싸 섹션을 쓴다: `[project."이름"]`.

## 항목

| 항목 | 뜻 | 기본값(설정 없을 때) |
|---|---|---|
| `match` | 프로젝트 판별용 원격 주소 조각·폴더 이름 | 없음, `[default]` 사용 |
| `audience` | 독자 유형(개발자·기획자). 고유명사 허용 여부가 갈린다 | 개발자 |
| `recipients` | 받는 사람 `이름\|역할\|직접전달 여부`. 직접전달 여부가 `직접전달 안 함` 이면 직접 보내지 않는다 | 없음, 사용자 본인에게만 |
| `channel` | 전달 채널 ID | 없음, 파일 경로만 보고 |
| `out_dir` | 산출물을 모을 폴더 | `docs/out` |
| `name_rule` | 파일 이름 규칙. 폴더 안에 `<이름>.html` | `{날짜}-{주제}` |
| `ticket_pattern` | 티켓 키 정규식(검사용) | 없음, 티켓 검사 생략 |
| `base_branch` | 사실 대조 기준 브랜치 | 저장소 기본 브랜치 |
| `docs_dir` | 저장소에 커밋하는 기술 문서 폴더 | 저장소 관례 |
| `precedent` | 문체 선례 저작자·프로젝트 | 없음, 공통 문체만 |

## 읽는 순서

1. 설정 파일을 찾는다. `DOC_KIT_CONFIG`, 없으면 `~/.config/doc-kit/projects.toml`.
2. 파일이 없으면 기본값 그대로 진행하고 보고에 "설정 없음 — 기본값" 한 줄을 적는다.
3. 프로젝트를 고른다. 먼저 되는 것을 쓴다.

| 순서 | 방법 | 쓰는 때 |
|---|---|---|
| 1 | 작업 지시·허브 프롬프트·역할 파일에 프로젝트명을 적는다(**기본 방법**) | 다른 프로젝트 문서를 맡을 때. 시작 스크립트가 프롬프트로만 값을 넘기므로 이 경로가 확실하다 |
| 2 | 환경 변수 `DOC_KIT_PROJECT`(보조) | 환경 변수가 터미널까지 전달되는지 확인된 뒤에만 쓴다 |
| 3 | git 원격 주소(origin)를 각 섹션 `match` 와 대조 | 대상 프로젝트 저장소 안에서 만들 때. 허브·하위 워크트리는 폴더 이름이 달라도 원격이 같아 잡힌다 |
| 4 | 저장소 폴더 이름을 `match` 와 대조 | 원격이 없을 때 |
| 5 | `[default]` 만 사용 | 위가 모두 안 맞을 때. 채널·받는 사람이 없어 파일 경로만 보고한다 |

4. 일치한 섹션 값을 `[default]` 위에 덮어쓴다.
5. 프로젝트명을 지정했는데 그 섹션이 없으면 `[default]` 로 진행하고 보고에 "프로젝트 섹션 없음" 을 적는다.

## 읽는 도구

`scripts/doc_config.py` 가 위 순서를 구현한다. 파이썬 3.11 이상은 내장 TOML 모듈을 쓰고, 그 미만(예: 3.9)은 이 틀이 쓰는 문법만 읽는 내장 간이 읽기로 대체한다.

```sh
python3 scripts/doc_config.py show --project <이름>      # 적용값 전체
python3 scripts/doc_config.py get channel --project <이름>
python3 scripts/doc_config.py get ticket_pattern         # --project 없으면 환경 변수·origin 순
```

새 허브(이 설정 저장소 안의 워크스페이스)는 origin 이 어느 `match` 에도 맞지 않는다. 역할 파일이나 작업 지시에 프로젝트명을 적어야 채널이 읽힌다.

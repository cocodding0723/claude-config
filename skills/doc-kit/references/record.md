# 기록 — 설계 기록·계획·계약·규약·명세·런북

저장소에 남는 기술 문서다. 근거 보존과 합의가 목적이다. 문체·머리말·장치는 [style.md](style.md), 골격은 [templates.md](templates.md).

## 순서

1. **종류를 고른다.** 아래 표. 맞는 종류가 없으면 가장 가까운 것을 쓰고 머리말에 이유를 적는다.
2. **선례를 연다.** 설정 `precedent` 가 있으면 같은 종류 선례를 하나 읽는다. 골격만 보고 쓰면 장치(빈칸 문장·뒤집는 조건 등)가 빠진다. 설정이 없으면 templates.md 만 쓴다.
3. **근거를 모은다.** 기준 커밋과 실측 날짜를 적는다. 근거가 없는 칸은 비워 두고 "미확인" 으로 쓴다.
4. **골격대로 쓴다.** 절 제목은 바꿔도 되지만 순서와 역할은 유지한다.
5. **자기 점검.** 아래 체크리스트. 결과는 사용자에게 경로와 함께 알린다. 커밋은 승인 뒤다.

## 종류

| 종류 | 언제 | 파일명 |
|---|---|---|
| 설계 기록 | 끝난 조사·계획을 근거 보존용으로 굳힐 때 | `<주제> (설계 기록).md` |
| 계획 | 구현 전. 한 PR 분량 / 장기 두 모양 | `<주제> 계획.md` |
| 계약 | 다른 팀·저장소·저작자에게 넘기는 명세 | `<주제> — <종류> 계약` |
| 규약 | 갈라진 트랙 사이의 합의 | `<주제> 규약.md` |
| 폴더형 | 여러 주 걸리는 리팩토링·이관 | `<작업명>/00 개요.md` ~ `0N …` |
| 데이터 명세 | JSON·CSV 추가·변경(같은 PR 에서) | `<파일>.json.md` |
| 런북·지시서 | 운영·다른 도구가 그대로 실행 | `<주제> 런북.md` / `… 지시서.md` |
| README·가이드 | 사용법·시작 안내 | 저장소 관례 |

변경 해설은 해설 유형, 결과 보고서는 보고서 유형, PR 본문은 `create-pr`, QA 는 `qa-checklist` 가 맡는다.

## 위치

- 저장소에 문서 폴더 관례가 있으면 따른다. 설정 `docs_dir` 이 있으면 그 폴더다.
- 폴더형은 하위 폴더로 묶는다. 하위 폴더 안 파일 링크는 퍼센트 인코딩 상대경로다.
- 개인용 메모·초안은 저장소 밖(scratchpad)에 둔다. 저장소 문서는 사용자 승인 뒤 커밋한다.

## README·가이드 일반 원칙

기록 종류에 맞지 않는 문서에 적용한다.

- 목적·독자·현재 문서를 먼저 확인한다. 대화에서 이미 정한 내용을 다시 묻지 않는다. 구현·제안·제공 데이터·실제 검증 결과를 구분한다.
- 핵심 결과·사용 방법을 먼저 배치한다. 낯선 개념은 그것을 쓰는 설명보다 앞서 정의한다.
- 식별자·조건·값·시점·예외·출처는 보존한다. 근거가 없으면 그럴듯한 설명으로 메우지 않는다.
- 절차는 준비 → 행동 → 관찰할 결과 순이다. 현재 없는 화면·기능·도구를 가정하지 않는다.
- 처음 읽는 사람 관점에서 목적·적용 환경·준비 조건·실패 처리·미확인 사항을 검토한다. 자체 검토를 독립 검수라고 부르지 않는다.
- 링크·표·용어·도식의 일치를 확인한다. DOCX·PDF·슬라이드는 그 형식의 렌더링 검증을 함께 한다.
- 한국어 문서는 [korean-technical-writing.md](korean-technical-writing.md) 를 필요한 만큼 읽는다.
- 사용자 원문과 무관한 파일을 바꾸지 않는다. 문서 작성 권한과 외부 게시 권한은 구분한다.

## 체크리스트

- [ ] 첫 문장이 결과·결정을 단정하는가
- [ ] 해설이면 머리말에 규모 줄이 있는가(기준 커밋·날짜 권장). 비해설 문서는 생략 가능
- [ ] 결정마다 근거와 기각안(또는 "다른 안 없음")이 있는가. 뒤집힐 수 있는 결정엔 뒤집는 조건
- [ ] 의도된 한계와 우연히 발견한 결함이 분리됐는가
- [ ] 숫자·`파일:줄`·커밋 해시로 근거를 댔는가. 추정은 추정이라고 썼는가
- [ ] 축약어·숫자 ID 를 첫 등장에 풀었는가
- [ ] 흐름·구조 설명에 그림(표·ASCII·mermaid)이 하나 이상 있는가
- [ ] 평서 `~다` 로 통일됐는가
- [ ] 사실이 바뀐 곳을 지우지 않고 정정 표식으로 덧썼는가
- [ ] 본문을 고쳤다면 그 절을 참조하는 요약 표·퀴즈·다른 문서를 같이 고쳤는가

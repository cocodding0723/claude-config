# 구조안

구조를 바꾸자는 제안을 **처음 보는 사람도 5분 안에 판단할 수 있는** 한 장짜리 HTML 로 만든다. 결정 카드·인과·길이·도식 규칙은 SKILL.md 공통 규칙이 정본이다. 여기에는 구조안만의 순서와 검사를 적는다.

## 순서 (바꾸지 않는다)

1. **쉬운 말 3줄 요약** — ① 지금 문제 ② 그래서 무엇을 바꾸나 ③ 그러면 무엇이 달라지나·사용자가 할 일. 한 줄에 한 문장, 합계 180자 이하, 괄호 금지.
2. **🙋 결정 필요 — 결정 카드.** 형식은 SKILL.md «결정 카드».
3. **📄 지금 구조 / 바뀌는 구조** — PUML 두 장을 나란히(또는 위아래). SVG 를 문서에 내장한다. 문제 위치 그림까지 3장이면 SKILL.md «도식 3장».
4. **🔄 주제별 before/after** — 주제마다 대표 코드 1곳, 각 10~20줄. 왼쪽 before, 오른쪽 after. 아래에 "무엇이 왜 달라지나" 한 줄.
5. **✅ 그대로인 것 / 없어지는 것** 표.
6. **🔄 진행 순서** — 번호 목록. 단계마다 검증 기준 한 줄.
7. **참고** (맨 아래, 접힘) — 파일 경로, 티켓, 커밋, 근거. 검수 기록도 `<details>` 안에 둔다.

## 글쓰기 규칙

- 본문은 쉬운 말이다. 기획자 독자면 고유명사(클래스·함수·파일 이름, 티켓·커밋 번호, 캐릭터 실명)를 코드 조각과 참고 칸에만 둔다. 본문에서는 역할로 부른다("효과 관리자").
- AI 내부 기호(P1·fixup·ctx_·D1·Q16 등) 금지.
- 수치·파일·동작은 설정 `base_branch` 에서 확인한 것만 쓴다. 확인 못 한 건 "(미확인)" 을 붙인다.
- before/after 코드는 실제 코드에서 발췌한다. after 는 제안 코드이므로 제목에 "제안" 을 붙인다.

## 만드는 법

1. `templates/doc.html` 을 복사해 자리표시(`{{…}}`)를 채운다.
2. PUML 은 `templates/before.puml`·`after.puml` 을 고쳐 `plantuml -tsvg` 로 렌더하고 SVG 를 문서에 내장한다. 외부 파일 참조는 금지다.
3. before/after 블록은 템플릿의 `<section class="ba">` 를 주제 수만큼 복제한다.
4. 검사: `python3 <doc-kit 경로>/scripts/check.py [--project <이름>] <문서.html>`. 프로젝트는 설정 읽기 규칙(config.md)으로 정한다. 실패 항목이 0개일 때만 완성으로 보고한다.
5. 저장·전달은 SKILL.md «저장·전달».

## 검사 항목 (check.py)

- 3줄 요약 박스 존재, 180자 이하
- 🙋 결정 섹션 존재
- 내장 SVG 2개 이상(지금/바뀌면)
- before/after 블록 1개 이상, 각 블록에 before·after 코드와 "왜" 한 줄
- 외부 스크립트·스타일 참조 없음(자체 완결)
- 본문(코드·참고 제외)에 고유명사 패턴(PascalCase 클래스명, 커밋 해시) 없음. 기획자 독자(설정 `audience` 또는 `--audience 기획자`)일 때만 검사한다. 설정 `ticket_pattern` 이 있으면 티켓 키도 본문에서 검사한다
- 내부 기호(P1·P2·P3, fixup, ctx_) 없음
- 결정 카드마다 인과 연결어(때문·그래서·그러면·하면·~면·므로·탓에·덕분) 1개 이상
- 결정 카드 본문 450자 초과는 경고, `--strict` 에서는 실패
- 검수 기록(제목·요약에 '검수' 포함)이 `<details>` 안에 있음

## 바뀐 곳 강조 도구

| 도구 | 사용 |
|---|---|
| `scripts/puml_diff.py before.puml after.puml` | 노드(`as 별칭`)를 비교해 추가=초록·변경=노랑·삭제=빨강 점선으로 칠한 `*.hl.puml` 과 범례를 만든다. 별칭은 before/after 에서 같은 대상이면 같게 쓴다 |
| `scripts/image_diff.py before.png after.png out.png` | 같은 크기 캡처 두 장에서 바뀐 영역에 빨간 상자를 그린다. 잡음이 많으면 `--threshold`·`--min-area` 를 조정한다 |
| `scripts/screen_flow.sh 영상.mp4 출력폴더` | 장면이 바뀌는 프레임만 모아 가로 띠(`flow-strip.png`)와 12초 미리보기(`preview.gif`)를 만든다 |

그림 섹션은 강조본을 쓰고 범례를 남긴다. 화면이 바뀌는 문서는 "📄 화면 변화" 섹션(before/after 캡처 비교 + 흐름 띠 + GIF)을 진행 순서 앞에 둔다.

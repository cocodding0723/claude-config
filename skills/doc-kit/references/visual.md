# 비주얼 변경 문서

화면이 바뀌는 변경을 받는 사람에게 보여 줄 때 쓴다. 받는 사람·전달 채널·직접 전달 허용 여부는 설정 `recipients`·`channel` 이 정한다. 값은 이 파일에 적지 않는다.

## 구성 (순서 고정)

1. **구조도** — PUML 로 렌더한 SVG. 첫 화면에 둔다.
2. **전후 비교** — 같은 해상도의 실제 촬영본을 이전(기준 브랜치)·현재(작업 브랜치) 나란히 놓는다. 바뀐 영역에 상자를 그린다(`scripts/image_diff.py`). 무엇이 정확히 바뀌었는지 표시한다.
3. **흐름** — 촬영 이미지를 이은 화면 흐름 띠. 장면이 바뀌는 프레임만 쓴다(`scripts/screen_flow.sh`). 화면 흐름 보드가 필요하면 `ux-flow-board` 스킬을 쓴다.

## 규칙

- 핵심만 심플하게 쓴다. 표·그림 위주이고 긴 문단은 쓰지 않는다.
- 촬영은 해상도를 하나로 고정한다. 해상도가 다르면 상자 비교가 어긋난다.
- 실제 촬영본이 없으면 "샷 없음" 을 밝힌다. 목업을 실제 화면처럼 쓰지 않는다.
- 받는 사람은 기획자 독자다. SKILL.md «독자 규칙» 의 기획자 규칙을 따른다.
- 받는 사람에게 직접 보내지 않는다. 설정이 직접 전달을 허용하지 않으면 사용자 채널로만 보낸다.
- 구조도의 상세 규칙은 SKILL.md «도식 3장 + 화면 샷».

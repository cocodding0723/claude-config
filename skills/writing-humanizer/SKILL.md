# 상투적인 AI 문체 정리

사실과 작성자의 의도를 보존하면서 읽는 데 방해되는 표현만 고친다. 사람처럼 보이게 하려고 경험·감정·사례·인용을 만들어내지 않는다.

- “X가 아니라 Y”, 결론을 다시 반복하는 한 줄 마무리, 중요성을 예고하는 도입을 실제 내용으로 바꾼다.
- 무조건 세 항목, 짧은 문장 연속, 대시 남발 같은 반복 리듬을 자연스럽게 정리한다.
- 과장된 영향·역사적 의미·판매 문구, 모호한 출처, 상투어를 근거와 구체적인 표현으로 바꾼다.
- 불필요한 굵은 글씨·제목·이모지와 대화용 인사·마무리를 덜어낸다.
- 불확실성을 나타내는 필요한 표현은 보존한다. 짧게 만들려고 확신 수준을 높이지 않는다.

이름은 Hermes 기본 `humanizer`와 구분한다. 이 스킬은 요청된 원고 편집에 적용하며 모든 답변을 강제로 다시 쓰지 않는다. 기본 출력은 최종 수정본 한 벌. 단계별 초안·비교는 요청했을 때 제공한다.

원본 패턴과 예시는 `references/upstream-SKILL.md`에 보존했다. 세부 판정이 필요할 때만 읽는다. 라이선스는 `LICENSE` 참고.

## 판정 모드

"판정만", "검사만", "어디가 AI 같아" 처럼 고치지 말라는 요청이면 원고를 바꾸지 않는다. 걸린 문장을 그대로 인용하고 패턴 이름(아래 분류의 이름)만 붙인다. 형식은 `> 인용 — 분류/패턴명` 한 줄씩. 걸린 게 없으면 없다고 쓴다. 점수·AI 확률은 내지 않는다.

## 한국어 패턴

목적은 읽기 쉬운 글이다. AI 탐지기 우회가 목적이 아니며, 저작자를 속이려는 재작성은 하지 않는다. 고유명사·수치·날짜·발화자가 있는 인용·법률 문구·업계 표준 용어(API·SDK 등)는 건드리지 않는다. 당위("~해야 한다")·추측("~일 수 있다")을 단정으로 바꾸지 않는다. 한 번 나온 표현은 대부분 정상이다. 같은 패턴이 몰려 있을 때만 고친다.

### 번역투
- **~에 대해 밀집**: 이 문제에 대해 논의했다 → 이 문제를 논의했다
- **~에 있어서**: 개발에 있어서 중요한 점 → 개발에서 중요한 점
- **가지고 있다 직역**: 강한 경쟁력을 가지고 있다 → 경쟁력이 강하다
- **추상 주어+만능 동사**: 이 결과는 개선 가능성을 보여준다 → 이 결과대로라면 개선할 수 있다
- **이중 조사**: 서버로의 전송 → 서버로 보내기
- **긴 앞 수식**: 어제 팀이 회의에서 정한 새 저장 규칙은 → 어제 회의에서 새 저장 규칙을 정했다. 이 규칙은

### 피동 남용
- **이중 피동**: 판단되어진다 → 판단된다
- **~에 의해**: 스크립트에 의해 생성된 파일 → 스크립트가 만든 파일
- **행위자 없는 처리형 반복**: 저장됩니다. 처리됩니다. 확인됩니다. → 앱이 저장하고, 서버가 확인한다

### 기계적 나열
- **열거 예고**: 크게 세 가지로 나눌 수 있다. 첫째, → 원인은 캐시, 권한, 네트워크다
- **먼저-반면-결국 문두 공식**: 문단마다 먼저/반면/결국 → 필요한 곳 하나만 남김
- **1) 2) 3) 산문 속 번호**: 1) 설치 2) 설정 3) 실행을 한다 → 설치하고 설정한 뒤 실행한다
- **굵은 라벨 목록**: **장점:** 빠름 / **단점:** 느림 → 빠르지만 메모리를 더 쓴다

### 과장·의의 부풀리기
- **의의 과장**: 시사하는 바가 크다 → 재시도 정책을 바꿔야 한다는 뜻이다
- **단순한 X를 넘어 Y**: 단순한 도구를 넘어 플랫폼으로 → 도구에 배포 기능까지 갖췄다
- **X에서 Y로 변환 공식 반복**: 소비에서 창작으로, 개인에서 팀으로 → 한 번만 쓰거나 직접 단언
- **감각 술어·사전 은유**: 지표가 적신호를 켰다 → 지표가 두 주 연속 떨어졌다
- **근거 없는 찬사**: 혁신적이고 강력한 기능 → 로그인 없이 저장되는 기능

### 상투어·결산 표현
- **결산어 남발**: 결론적으로/이를 통해/따라서 연발 → 한두 개만 남김
- **분열문**: 중요한 것은 방향이다 → 방향이 중요하다
- **~하는 이유다 도치**: 그래서 캐시를 끈 이유다 → 그래서 캐시를 껐다
- **~할 때다 결말**: 이제 바꿀 때입니다 → 다음 스프린트에 바꾼다
- **과제 문패 문장**: 물론 과제도 남아 있다. → 남은 과제를 바로 첫 문장으로 쓴다
- **~다는 것이다 결말 반복**: 느리다는 것이다 → 느리다
- **출처 없는 ~라는 분석이다**: 수요가 늘 것이라는 분석이다 → 수요가 늘 수 있다 (출처가 있으면 출처를 밝힘)
- **막연한 기대 마무리**: 앞으로의 행보가 기대된다 → 다음 단계가 있으면 그것을, 없으면 삭제

### 영어 인용 과다
- **괄호 영어 매번 병기**: 지연 로딩(Lazy Loading)을 매번 → 첫 등장만 병기
- **광고성 외래어**: 인사이트를 리버리지해 시너지를 → 결과를 활용해 함께 효과를 낸다. 표준 기술 용어는 그대로 둔다

### 문장 끝 반복·리듬
- **같은 종결 4문장 연속**: ~한다. ~한다. ~한다. ~한다. → 종결과 길이를 섞음
- **~고 있다 자동 진행형**: 사용자가 읽고 있다 → 사용자가 읽는다
- **~할 수 있다 반복**: 문단에 4번 → 일부만 다른 완곡으로 나눔. 단정으로 바꾸지 않음
- **연결어미 뒤 쉼표**: 저장하고, 닫으며, 끝낸다 → 저장하고 닫으며 끝낸다
- **존댓말 등급 혼재**: 합니다·해요·한다 섞임 → 원문 주된 등급 하나로
- **같은 대상 동의어 순환**: 사용자·고객·이용자 → 한 단어로 고정

추가 데이터 받기 흐름

게임 밖에서 받아 와야 하는 데이터(시즌 이벤트, 노벨, 스토리·취경 판)를 받을 때 어떤 창이 뜨고 어디로 이어지는지, 보이는 UI가 달라지는 경우마다 실제 화면으로 이었습니다. UX 피드백용입니다.

Boot · 꼭 받는 팩

로딩 90% 뒤, 열린 시즌 이벤트(렛츠스터디·독서왕·픽업)의 팩이나 리모트 컨피그로 지정한 팩이 기기에 없을 때. 건너뛸 수 없다. 한 번이라도 받은 팩(부팅·입장·뒤에서 받기)은 다시 알리지 않는다

29화(연미정)
  • 연미정 그림(0.07 MB)은 9/28 노벨 팩에 합쳤다. 29화도 다른 화와 같다.
  • 노벨 팩은 설치 직후 스토어가 받아 두므로 대부분은 창 없이 바로 재생.
  • [나중에]·[취소]·실패 뒤 [취소] → 29화만 안 열리고 목록에 남는다. 보상·진행은 그대로. 3번 이상 실패하면 문의 안내 창.

유저 조작 없이 도는 자리 — 자격증 그림, 엔딩 BGM

창 없는 받기
  • 창도, 입력 잠금도, 재시도 질문도 없다.
  • 못 받아도 화면은 그대로 진행된다(대체 그림·무음). 다음에 들어오면 다시 시도한다.
  • Android 동의 시트도 띄우지 않는다.
참고 · 수험생 키우기 확장팩

같은 회사 전작. 확장팩 진입 때 총 크기를 묻고 MB 진행을 보인 뒤 저절로 이어 감(AVD 9/27)

확장팩진입할 때

피드백 받고 싶은 것

  1. 두 확인 창의 말투. 부팅은 “진행하려면 … 받아야 합니다.” [받기](안내), 인게임은 “… 지금 받을까요?” [나중에] [받기](질문). 이유(“이벤트를 즐기려면 …”)를 넣을지, 말투를 맞출지.
  2. 문의하기 시점. 3번째 실패부터 [문의하기]를 보입니다(리모트 컨피그). 횟수와 안내 문구가 괜찮은지.
  3. 재시도 창의 오류 문구. “AP-STALL (PackReadingKing: Stalled)”처럼 내부 팩 이름이 유저에게 보입니다. CS 분류용 코드만 남길지.
  4. 진행률 막대. 막대 왼쪽 끝에 짙은 얼룩(기본 둥근 사각형 그림을 늘려 쓴 탓). 디자인 리소스로 바꿀지.

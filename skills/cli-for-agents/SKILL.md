# cli-for-agents

에이전트는 화살표 키를 누를 수 없고, 긴 설명서를 다 읽으면 맥락이 찬다. 모든 입력은 플래그로 받고, 실패는 바로 알린다.

## 규칙

| 항목 | 기준 |
|---|---|
| 대화형 입력 없음 | 모든 값은 플래그·환경 변수·stdin 으로 받는다. `read`·확인 프롬프트는 TTY 일 때만, `--yes` 로 건너뛴다. 값이 없으면 기다리지 말고 종료한다. |
| 계층형 도움말 | 인자 없는 실행은 하위 명령 목록만, `<명령> --help` 는 그 명령만. 모든 `--help` 끝에 복사해 쓸 **예시** 2~3줄. |
| 오류 메시지 | `원인 + 조치` 한두 줄, 맞는 실행 예 포함. 예: `오류: PROJ 미지정. PROJ=/path bash Tools/verify/verify.sh --editor` |
| 반복 실행 안전 | 두 번 돌려도 결과가 같다. 이미 된 일은 "이미 완료"로 끝낸다. 잠금은 `mkdir` 원자 잠금 + 소유자 기록. |
| 파괴적 동작 | `--dry-run` 으로 계획만 출력. 삭제는 `${VAR:?}` 가드, 임시 경로는 `mktemp -d`. |
| 출력 | 사람용 기본 출력 + `--json`(한 객체, stdout 전용). 진행 로그는 stderr. 결과 파일 경로는 마지막 줄에 고정. |
| 종료 코드 | 0 성공 / 1 검증 실패(빨강) / 2 사용법 오류 / 3 환경 문제(Unity·네트워크·잠금). 도움말에 표로 적는다. |
| 시간 | 오래 걸리면 제한 시간 옵션과 기본값을 둔다. 끝없는 대기 금지. |

## 이 저장소 대상 예

- `Tools/verify/verify.sh` — `--editor`·`--batch`·`--record` 플래그, `summary.json` 경로 출력, 에디터 미기동·잠금 점유를 종료 코드 3으로 구분.
- `Tools/game-data-web` — 서버 기동 외에 fetch·검증을 플래그로 부르는 비대화형 진입점, `--json` 결과.
- `~/.config/lrm-hubs/*.sh` — `pick_host.sh`·`unity_slot.sh` 같은 판정 스크립트는 결과를 한 줄(또는 `--json`)로, 대기는 제한 시간과 함께.

## 검토 절차

1. 인자 없이, `--help` 로, 필수 값 빠뜨리고 실행했을 때의 동작을 **코드를 읽어** 판정한다(실행은 사용자가 시킬 때만).
2. 위 표 항목별 통과·미달·해당 없음을 적는다.
3. 고칠 점은 우선순위 순으로 제안하고, 수정은 승인 뒤 한다.

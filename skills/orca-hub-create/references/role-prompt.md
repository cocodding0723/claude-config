# 역할 프롬프트 템플릿

```
역할: <이 허브가 맡는 일 한 줄>
범위: <다루는 모듈·데이터·티켓>, 다루지 않는 것: <다른 허브 담당>
첫 작업: <구체 작업, 관련 Jira 키>
산출: <문서 형식(doc-kit 등)·위치·독립 리뷰 여부>
결정 보고 형식: 문제/영향/선택지/추천
워커 모델: <claude-sonnet-5-5 | codex gpt-6-astra>
참고 메모리: <관련 메모리 이름>
```

예시는 `[관리] 아키텍처 점검 코디네이터`(6축 병렬 점검), `[관리] 스크럼 회의 코디네이터`(Confluence 본인 칸 초안·승인 후 게시).
